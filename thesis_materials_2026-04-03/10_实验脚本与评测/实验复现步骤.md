# 实验复现步骤（论文附录可用）

## 1. 环境准备

1. Python 环境：使用项目指定环境（如 `F:\\anaconda\\envs\\pytorch`）。
2. 安装后端依赖：
   - 进入 `backend` 目录
   - 执行：`pip install -r requirements.txt`
3. 安装前端依赖：
   - 进入 `frontend` 目录
   - 执行：`npm install`

## 2. 启动系统

1. 启动后端：
   - 目录：`backend`
   - 命令：`python app.py`
2. 启动前端：
   - 目录：`frontend`
   - 命令：`npm run dev`
3. 浏览器访问前端地址（Vite 默认地址）。

## 3. 端到端验证（推荐）

1. 在上传页选择 `testpicture-1.jpg`，点击“开始打谱”。
2. 观察是否依次得到：
   - CV 识别结果
   - 拓扑序列结果
   - LLM 推理结果
   - 打谱渲染结果
3. 对照输出文件：
   - `05_论文可用JSON与XML/testpicture-1_pipeline_result.json`
   - `05_论文可用JSON与XML/musicxml_full_from_testpicture.xml`

## 4. 交互修正回路验证

1. 在“特征提取”页面选中某个 `group_x`。
2. 修改字段或标记删除后，点击“应用修正并重跑流程”。
3. 检查后续页面（topology/llm/xml）是否刷新并与修正一致。

## 5. 脚本级测试（可选）

1. 运行聚类/拓扑测试脚本（见 `10_实验脚本与评测` 目录）。
2. 运行顺序验证脚本：`test_group_order_on_testpicture.py`。
3. 运行渲染与转换相关脚本：`test_score_model_transformer.py`、`convert_llm_json_to_score_model.py`。

## 6. 论文记录建议

1. 记录输入文件名、时间、输出 JSON/XML 文件路径。
2. 对每次调参保留“前后对比图”与“关键统计值”。
3. 在论文实验部分统一使用同一批样本与同一版本代码。
