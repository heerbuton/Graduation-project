- 案例是否真实存在：是。
- 证据来源位置：
  - 数据文件：`llm_repair_case_runtime_2026-04-06.json`
  - 代码位置：

    - `backend/pipeline/llm_module.py:392-405`（`_repair_invalid_notes`）
    - `backend/pipeline/llm_module.py:483-486`（pitch/octave/duration 严格枚举校验）
- 原始输入片段（topology 输入）：

```json
{
  "group_1": {
    "fingering": "勾",
    "finger": "大",
    "position": "九",
    "string": "一",
    "right_fingering": "勾",
    "left_fingering": "",
    "left_finger": "大",
    "hui": "九",
    "xian": "一",
    "components": []
  }
}
```

- 错误输出片段（模型草稿）：

```json
{
  "group_id": "group_1",
  "pitch": "9",
  "octave": "7",
  "duration": "32",
  "action": "勾",
  "string": "一",
  "position": "九",
  "finger": "大",
  "new_measure": false
}
```

- 校验失败信息 / 错误类型：
  - `repair_prompt_failure_reason = "字段 pitch 非法: '9'"`

- 修复后结果片段：

```json

  "duration": "4",

  "string": "一",

  "finger": "大",
```

- 运行侧证据：
  - `llm_call_count = 2`（首轮 + repair 轮）
  - 含原始修复提示：`raw_repair_user_prompt`
