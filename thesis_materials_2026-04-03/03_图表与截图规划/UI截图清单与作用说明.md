# 系统 UI 截图清单与作用说明（规划文档）

> 按本清单截图即可覆盖论文“系统实现 + 实验展示 + 可视化交互”主要图证，不在此文档中直接放截图。

## 1. 截图清单（建议最少 10 张）

1. 上传首页（未选择图片）
   - 作用：展示系统入口与用户操作起点。
2. 上传后预览 + “开始打谱”按钮
   - 作用：说明人机交互触发方式。
3. 特征提取页（左原图 + 右交互校对图，4:6 布局）
   - 作用：展示“原图对照 + 识别可视化”。
4. 特征提取页（悬停提示框）
   - 作用：展示字段可解释性（Right/Left/Finger/Hui/Xian）。
5. 特征提取页（编辑面板打开）
   - 作用：展示可编辑、可删除的人工纠错能力。
6. 点击“应用修正并重跑流程”后的状态提示
   - 作用：展示局部重算闭环。
7. 拓扑序列页（卡片网格）
   - 作用：展示聚合后结构化语义结果。
8. 乐理推理页（LLM 结果卡片）
   - 作用：展示模型输出结构与字段完整性。
9. 打谱渲染页（ScoreModel 结果）
   - 作用：展示最终可读乐谱效果。
10. 全流程完成态（步骤条点亮）
   - 作用：展示端到端流程闭环。

## 2. 每张截图建议标注

1. 图号（如“图4-3”）
2. 当前阶段（upload/cv/topology/llm/xml）
3. 关键控件（按钮、状态信息、计数信息）
4. 输入/输出关系一句话（例如“该图展示 YOLO 检测后聚合框可交互修正”）

## 3. 截图操作规范（保证论文观感一致）

1. 分辨率建议：`1920x1080` 或 `2560x1440`
2. 浏览器缩放：固定 100%
3. 同一主题与字体，不混用不同样式版本
4. 截图范围尽量覆盖主内容区，不截系统任务栏
5. 文件命名建议：`ui_01_upload_idle.png`、`ui_02_cv_overlay.png`

## 4. 与论文章节的映射建议

1. “系统实现”章节：图 1~6
2. “关键算法流程”章节：图 3、7、8
3. “结果展示”章节：图 9、10
4. “可解释性/可用性”章节：图 4、5、6
