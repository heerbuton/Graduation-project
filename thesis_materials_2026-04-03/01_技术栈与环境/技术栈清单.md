# 技术栈清单（可用于论文“开发环境与技术选型”）

## 1. 系统总体技术路线

- 架构模式：前后端分离 + 算法流水线（CV -> 拓扑 -> LLM -> MusicXML）
- 前端：Vue 3 单页应用
- 后端：Flask API 服务
- 算法：YOLO（Ultralytics）+ SAHI 切片推理 + 拓扑聚合规则
- 推理：LLM（Qwen 兼容接口）
- 编码输出：MusicXML + ScoreModel JSON

## 2. 前端技术栈（来源：`frontend/package.json`）

- 核心框架：`vue@^3.3.4`
- HTTP 通信：`axios@^1.6.0`
- 构建工具：`vite@^4.4.5`，`@vitejs/plugin-vue@^4.2.3`
- 样式体系：`tailwindcss@^3.3.5` + `postcss@^8.4.31` + `autoprefixer@^10.4.16`
- 运行方式：
  - 开发：`npm run dev`
  - 构建：`npm run build`
  - 预览：`npm run preview`

## 3. 后端技术栈（来源：`backend/requirements.txt`）

- Web 框架：`Flask==3.0.0`
- 跨域支持：`Flask-Cors==4.0.0`
- 图像处理：`opencv-python==4.8.1.78`
- 数值计算：`numpy==1.26.2`
- 检测模型：`ultralytics==8.0.222`
- SAHI 切片推理：`sahi>=0.11.0,<0.12`
- HTTP 调用：`requests==2.31.0`
- XML 处理与校验：`lxml==5.3.0`

## 4. 关键模块映射（便于论文写“模块职责”）

- `backend/pipeline/cv_module.py`
  - YOLO/SAHI 推理入口，支持召回优先模式与单模型模式。
- `backend/pipeline/topology_module.py`
  - 识别框去重、聚类、语义字段提取、`group_x` 排序与减字序列构造。
- `backend/pipeline/llm_module.py`
  - 构造 LLM 提示词、调用推理接口、结构化 JSON 解析与修复。
- `backend/pipeline/musicxml_encoder.py`
  - 将 LLM 结果编码为 MusicXML，支持结构校验。
- `frontend/src/App.vue`
  - 上传、分步可视化、交互修正、重跑后续流程、结果渲染。

## 5. 论文可直接引用的一句话

本系统采用“Vue3 + Flask + YOLO/SAHI + LLM + MusicXML”分层流水线架构，实现了从古琴减字谱图像输入到结构化乐谱输出的端到端自动化处理。
