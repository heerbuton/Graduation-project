# 论文素材总包（系统实现）

本目录用于毕业论文“系统实现/系统设计/实验结果”章节的集中取材，所有内容均为**复制**得到，未移动原文件。

## 目录结构

1. `01_技术栈与环境`：前后端技术栈、依赖清单。
2. `02_需求与接口`：系统功能需求列表、核心 API 文档片段、核心样本统计与图注建议。
3. `03_图表与截图规划`：UI 截图清单、总体架构图说明与提示词、核心时序图说明与提示词。
4. `04_论文可用图片`：输入图、识别框图、聚类组框图、排序图、渲染结果图。
5. `05_论文可用JSON与XML`：流水线关键中间结果与 MusicXML 结果。
6. `06_代码快照与参考文档`：后端主入口、各 pipeline 模块、前端主界面与组件、项目说明文档。
7. `07_既有paper_assets精选`：既有论文资料中可复用的高价值文档与图。
8. `08_论文可复用文字素材`：可直接改写后用于论文正文的段落。
9. `09_附加资料`：阶段性归档报告、当前论文文档副本。
10. `10_实验脚本与评测`：实验复现脚本、测试脚本、评测脚本与说明。

## 可直接优先使用的素材（建议）

1. 输入与检测对比：`04_论文可用图片/testpicture-1.jpg` + `testpicture-1_red_boxes.jpg`
2. 聚合拓扑展示：`04_论文可用图片/testpicture-1_group_boxes_only_v3.jpg`
3. 排序规则展示：`04_论文可用图片/testpicture-1_group_order.jpg`
4. 终端渲染效果：`04_论文可用图片/scoremodel-after-measure-wrap-fix.png`
5. 端到端结构化结果：`05_论文可用JSON与XML/testpicture-1_pipeline_result.json`
6. 音乐编码证据：`05_论文可用JSON与XML/musicxml_full_from_testpicture.xml`

## 证据链建议（写论文时）

1. 原始图片 -> YOLO 检测 -> 拓扑聚合 -> LLM 输出 -> ScoreModel 渲染 -> MusicXML 文件。
2. 对每一步配 1 张图 + 1 段关键字段说明（来源于 `05_论文可用JSON与XML`）。
3. 图表部分优先使用 `03_图表与截图规划` 的提示词生成规范化架构图/时序图。
