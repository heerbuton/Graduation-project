# 第6周进展记录：同步物理等比放大机制与大模型陷阱排查

## 工作完成情况

本周的工作在解决密集细小特征的检测问题上取得了一些进展。在对早期的数据切分引擎进行排查后发现，由于原始部分古籍图片的宽幅较窄，在使用预设的固定窗口进行滑动提取时，未能产生实质性的截取和放大效果，依然向模型输入了密集的像素群。为了缓解这一问题，我开发了智能Padding边界防形变模块，在古籍窄边的无用区域使用基础灰色进行填充扩边，减弱了图形拉扯形变。紧接着，我上线了微型焦点切片尝试：将有效切片尺寸大幅缩小，然后再进行线性等比放大，将其提升回主流模型输入的主尺寸环境，相应的YOLO标注包围框坐标也同步等比例转换。该特写方案将部分古籍扩增为了包含较多目标标注框的高分辨率特写图库。此外，经过交叉验证与参数量评估，我尝试了采用较轻量化的骨干网络策略，这一定程度上规避了过大参数在分布不均的数据集上带来的过拟合和性能衰减风险。

## 下阶段工作内容

目前，`V07`版本的高分辨率切片数据集及扩容逻辑已基本开发完毕。下周的核心任务是开展“`V07_Hybrid`”混合微调实验。首先，我将编写数据清洗与划分脚本，整合局部特写数据与长尾补偿数据。在划分过程中，我将执行数据隔离：对包含人为合成或拼贴干扰的图像尽量划入训练集，而验证集则尽量多地使用纯净的原生标注图像，以此增强模型评估指标的客观性。随后，我计划采用Ultralytics Python API来控制YOLO权重的微调流程。针对Windows环境下常见的显存碎片化和多线程读取问题，我将在启动脚本中加入`resume=True`断点续训机制，并调整多线程数据加载配置，以维持系统在长时间训练过程中的稳定性，力求产出具备更加稳定检测能力的模型权重，并完成这一阶段的实验记录。
